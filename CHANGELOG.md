# Changelog

## 1.1.0 (unreleased)

### CLI

* Hostnames as targets: `georecon example.com` resolves the name (IPv4 first) and looks up
  the resulting address.
* Batch mode: several targets per run, `--file targets.txt` (or `-` for stdin).
* `--map` / `--open-map` print (and open) the OpenStreetMap link for the resolved coordinates.
* `--selftest` checks that every provider answers, with per-provider latency, without
  requiring a lookup.
* `--retries N` for flaky networks; the HTTP layer now retries with backoff and the tool
  keeps working when a single provider is down.
* Fourth DNS blocklist (PSBL) and correct handling of `127.255.255.x` rate-limit answers,
  which used to be counted as listings (false positives).
* JSON output carries the requested `target` and `schema_version: 2`, and batch runs return
  both `results` and `errors`.
* Requires Python 3.10+, type annotated (mypy clean) and linted with ruff.

### Android app

* Hostnames are supported, resolved through DNS-over-HTTPS, and the origin name is shown
  above the address.
* Full English/Spanish localization (`gen_l10n`), following the system language.
* "Open on map" button and app bar action (OpenStreetMap) when coordinates exist.
* Pull-to-refresh on the home and result screens; the result screen re-runs the lookup.
* New launcher icon (adaptive, generated by `tools/generate_icon.py`).
* Smaller downloads: native libraries are compressed inside the package and the release is
  split per ABI (8.2 MB arm64, 7.7 MB armeabi-v7a, 8.3 MB x86_64 instead of one 48 MB APK).
* Tests: 9 (7 live network + 2 widget, including a Spanish-locale rendering check).

### Repository

* MIT `LICENSE`, `CHANGELOG.md`, GitHub Actions workflow (ruff, mypy, pytest, Flutter
  analyze/test, release APK build).
* Version sources consolidated: the CLI takes its version from the installed package
  metadata.

## 1.0.0

* First release: Python package + CLI (`georecon`) and Flutter app, published as
  `GeoRecon-plus.apk`.
* Keyless reputation via DNS blocklists (Spamhaus, SpamCop, Barracudacentral) with optional
  AbuseIPDB key from the environment, never hardcoded.
* No API keys in the repository, clear handling of private/documentation addresses,
  `--json` output, cross-platform (no bash required, `NO_COLOR`, legacy-console safe).
